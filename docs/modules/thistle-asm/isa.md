# isa

Thistle32 instruction layout: `I_SZ`, `MEM_SZ`, `TEXT_AT`, `Op`, `Form`, `Ins`, `INS`, `BY_NAME`, `BY_OP`. `reg` and `rname` translate register names, `word` emits an encoded instruction, `DecIns` and `decode` describe decoded fields, and `text` formats disassembly. This is the Thistle32 instruction set, not RV64GC.
