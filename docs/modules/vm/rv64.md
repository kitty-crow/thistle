# vm/rv64

`Rv64` adapts hosted processes to the canonical native RV64 instruction core. It services Linux ABI requests with the live `Sys` VFS, streams and credentials, coordinates guest harts, and flushes shared file mappings. It contains no second instruction interpreter. Hosted file reservations use `thistleMapHostFile` and `thistleUnmapHostFile` so instruction access checks use the same address-space tables.
