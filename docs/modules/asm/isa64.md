# isa64

Thistle64 instruction layout: `I64_SZ`, `MEM64_SZ`, `TEXT64_AT`, `Op64`, `Form64`, `Ins64`, `INS64`, `BY64_NAME`, `BY64_OP`. `xreg`, `freg`, `xname`, `fname` translate integer and floating register identifiers. `word64` and `fword64` encode instructions, while `Dec64`, `decode64`, `text64` support decoding and display.
